# Public evidence-sharing controls

- This repository is PUBLIC by the Ajjil owner's explicit request. Anyone may view and clone it, including after a later visibility change if forks/caches exist.
- Only allowlisted anonymous public-page screenshots and an empty admin login form are copied from the private Web UAT branch. Inspect each image and PDF manually before authorizing upload.
- A report claim is not a substitute for its original HTTP/DOM/log evidence; limitations are described in the gallery and report.
- Do not add raw authenticated captures, admin settings screenshots, Unifonic values, tokens, emails, customer information, server logs, original source PDFs, or exploitable proof-of-concept payloads.
- Do not expose unpublished critical security weaknesses. Share sensitive technical details privately with MIT through an approved channel.
- Repository owner should review the public visibility and contents after publication.
